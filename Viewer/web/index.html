本页面会自动发现同一局域网内的 EpicSpark 游戏并显示游戏内主摄像头（中摄像头）画面。

  • F 进入 / 退出全屏

  • D 打开 / 关闭设备列表
  • 找不到游戏？确认两台设备在同一网段，或在游戏主机的防火墙里放行 UDP 45230 / TCP 45231
  • 仍找不到：python Viewer/epicspark_viewer.py --game 游戏主机IP:45231
