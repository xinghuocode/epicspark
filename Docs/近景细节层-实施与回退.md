# 近景细节层：实施说明与回退手册

> 目的：解决"模型放进场景被放大后，第一人称贴近看糊成色块"的问题。
> 状态：**代码已实现，编译验证见文末**。默认开启，可 3 种方式关闭，2 步完全还原。

---

## 一、问题回顾（为什么要做这个）

| 事实 | 数值 |
|---|---|
| GLB 自带图集 | 2048×2048，单张 baseColor，无 normal / roughness / AO |
| 模型原生尺度 | 约 0.62–0.99 m 归一化立方体 |
| 原生尺度下的纹素密度 | **741 texel/m**（合格，属于"可近看"） |
| 放进场景后（12 m 宽建筑） | 放大约 19.3 倍 → **38 texel/m** |
| 12 m 处 1 纹素占屏 | 2 px（清晰） |
| 1.5 m 处 1 纹素占屏 | 约 16 px（糊） |
| 若靠提高单张图分辨率 | 需 8192 → 357 MB/模型；16384 → 1.4 GB/模型（不可行） |

结论：单张贴图的密度上限已用尽，只能靠**独立平铺的第二层细节**把近距离密度补回来。

## 二、实现方式（没有自写 shader）

复用 URP 14 Lit **内置的 detail map 通道**，只改材质属性：

```
detailUv = uv0 * _DetailAlbedoMap_ST.xy + _DetailAlbedoMap_ST.zw   (LitInput.hlsl:282)
albedo  *= lerp(1, 2 * detailAlbedo, detailMask)                    (LitInput.hlsl:212-228)
normalTS = BlendNormalRNM(normalTS, detailNormalTS)                 (LitInput.hlsl:230-247)
```

关键点：
- 细节图**均值 0.5** → 内部 `×2` 后正好是中性 1.0，不改变整体明暗；
- 细节图必须 **linear = true**，否则 0.5 灰被 sRGB 解成 0.214 线性，整个模型会变暗 2.3 倍；
- 细节图 wrapMode 必须 **Repeat**（原有图集是 Clamp）；
- 平铺次数由**模型自身 UV 密度**算出：`ST = 26 / (UV密度 × 模型对角线)`，
  单位是"每个模型重复 26 次"，**与放置尺寸无关**，所以放大多少倍都不影响颗粒的物理尺寸。

### 改动清单

| 文件 | 改动 |
|---|---|
| `Assets/Scripts/Loading/DetailSurface.cs` | **新增**（约 300 行）。程序化生成可平铺 256² 高度场 → albedo（线性、均值 0.5、±7%）+ 法线（DXT5nm 打包），并挂到材质。 |
| `Assets/Scripts/Loading/GlbModelLoader.cs` | 3 处小改（+5/−2 行）：`CreateMaterial` 增加 `Mesh mesh` 参数、调用点传 `mesh`、函数末尾加 `DetailSurface.Apply(material, mesh);` |
| `Assets/Editor/DetailLayerProbe.cs` | **新增**。编辑器诊断探针，不改运行时代码，可随时删除。 |

不新增任何美术资源、贴图文件、shader、第三方包；不动模型、不动放置尺寸、不动 `SceneAssembler`。

## 五、已知限制

1. **发布包（Build）里可能失效**：`_DETAIL_MULX2` 是 `shader_feature_local`，
   变体是否保留取决于"打包时被引用的材质"。本项目的材质是运行期生成的，
   因此在 **Player 构建**中该变体可能被剔除 → 细节层静默失效（不会报错、不会变黑）。
   编辑器 Play 模式不受影响。若以后要出包，需要加一个 Shader Variant Collection 或一个引用该关键字的 .mat。
2. **平铺密度是按模型平均 UV 密度算的**，同一模型上不同 UV 岛的密度有 ±30% 波动，
   颗粒尺度会略有差异（因为是各向同性噪声，肉眼基本不可见）。
3. **法线按 DXT5nm 打包**（A = x, G = y），在 D3D11 / 支持 DXT5nm 的平台上正确。
   若移植到定义了 `UNITY_NO_DXT5nm` 的平台，把 `UseNormalMap` 置 `false` 即可。
4. **重复感**：单一平铺在极大平面上仍可能看出规律。URP 的 detail 只支持一层，
   要彻底消除需要 macro variation（第二层低频调制），属于后续可选优化。

## 六、离线验证结果（Unity 之外）

用模型自带贴图 + 透视校正 UV + 平滑法线做的软件光栅渲染，同一机位（距墙 2 m）对比：

| 图 | 说明 |
|---|---|
| `Temp/glbprobe/d_before.png` | 无细节层：墙面糊成一片，只有双线性插值的色块 |
| `Temp/glbprobe/d_after.png` | 加细节层（albedo 层，±7%，每模型 26 次平铺）：出现细密的石粒/灰泥质感 |
| `Temp/glbprobe/v2_whole.png` | 整栋入画：证明自带图集本身是有细节的，糊纯粹来自放大 |

参数选择依据：`ST(church) = 26 / (0.3615 × 1.39) ≈ 51.7`，即 12 m 建筑上约 1 m 一个平铺周期，
256² 贴图 → 约 4 mm/纹素，正好覆盖"近距离可见但图集没有"的那一个数量级。
